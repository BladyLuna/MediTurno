# Workflow de Desarrollo

Antes de programar:

1. Leer CLAUDE.md
2. Leer reglas de negocio
3. Leer roadmap

Al desarrollar una funcionalidad:

1. Crear migración
2. Crear modelo
3. Crear controlador
4. Crear validaciones
5. Crear vistas
6. Crear rutas
7. Crear pruebas

Antes de finalizar:

1. Ejecutar tests
2. Revisar permisos
3. Revisar reglas de negocio
4. Actualizar documentación

Nunca:

* Hardcodear credenciales
* Saltarse validaciones
* Ignorar SoftDeletes
* Ignorar auditoría
