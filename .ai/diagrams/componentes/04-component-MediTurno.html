MediTurno — Diagrama de Componentes

Sistema de Gestión de Turnos del Personal de Salud — UML Component Diagram

Cliente (Frontend)

  • • Blade Templates + Bootstrap 5 — Vistas HTML responsive
  • • FullCalendar.js (CDN) — Calendario mensual con colores
  • • JavaScript mínimo — Alertas y confirmaciones
  • • Roles: Admin, Jefe de Servicio, Personal

Backend (Laravel 10)

  • • 8 Controllers (Auth, Admin, Calendar)
  • • 7 Models Eloquent con softDeletes()
  • • Middleware: CheckRole + Throttle (5/min)
  • • Gates & Policies (sin paquetes externos)
  • • Form Requests para validación

Base de Datos (MySQL 8)

  • • 7 tablas: users, hospital_services, staff
  • • shift_templates, service_shift_templates
  • • shift_assignments (sin turnos traslapados)
  • • audit_logs (bitácora de auditoría)
  • • Soft deletes en todas las tablas

Seguridad

  • • CheckRole Middleware — control por rol
  • • Throttle:5,1 — anti brute-force login
  • • Gates & Policies — autorización nativa
  • • CSRF (@csrf) + XSS (Blade escape)
  • • Hash bcrypt + Audit Logs + HTTPS

Infraestructura

  • • Docker: PHP 8.2-FPM + Nginx + MySQL 8
  • • Render — Hosting producción
  • • GitHub Actions — CI/CD + Tests
  • • GitHub Pages — Landing page estática
  • • DomPDF + Maatwebsite (PDF/Excel)

Reglas de Negocio Clave

  • • ❌ No se permiten turnos traslapados
  • • 🔒 Solo admin crea/edita usuarios
  • • 👁️ Jefe ve solo sus servicios
  • • 👤 Personal ve solo sus turnos
  • • 📝 Todo cambio registrado en audit_logs
